# /problems - 난이도별 문제 생성

샘플 대화에서 확인된 3가지 수준의 문제를 생성한다.
단순 계산 연습이 아니라, 개념을 "실제로 다룰 수 있는가"를 검증하는 문제.

## 사용법
```
/problems [주제] --level [기초|수학|전공] --count [문제수, 기본 4] --from [drafts/[주제]-build.md]
```

## 레벨 정의

### --level 기초
대상: 개념을 처음 접하는 학습자
기준: 정의와 기본 공식을 적용하면 풀 수 있는 문제
형식: 주어진 값을 대입하여 계산 → 결과 해석
예시 유형: "pH가 3인 용액의 수소 이온 농도는?"

### --level 수학
대상: 기본 계산을 할 수 있는 학습자
기준: 로그의 성질(덧셈, 뺄셈, 지수 변환)을 활용해야 하는 문제
형식: 식을 세우고 변환 과정을 거쳐 해를 구하는 문제
예시 유형: 샘플 대화의 "박테리아 증식", "pH 역산" 수준
힌트 포함: 풀이 접근법 한 줄 제공

### --level 전공
대상: 해당 분야의 실제 데이터를 다루는 학습자
기준: 실제 연구/실험에서 나오는 수식과 데이터 활용
형식: 배경 설명 → 조건 → 다단계 계산 → 결과의 의미 해석
예시 유형: 샘플 대화의 Nernst 방정식, qPCR, Gibbs Free Energy 수준
도메인: /build에서 사용한 --context 도메인 우선 적용

## 문제 구조 (모든 레벨 공통)
```markdown
[문제 N] [제목]

[배경 설명 — 왜 이 계산이 필요한지]

조건:
- [변수 1]
- [변수 2]

질문: [구하는 것]

(힌트: [접근법 — 수학/전공 레벨만])
```

## 출력
`drafts/[주제]-problems-[level].md`에 저장

## 품질 기준
- 답이 계산 가능해야 함 (수치가 주어진 문제는 답 검증 필수)
- 전공 레벨 문제는 실제 생물학/물리학/CS 상수값 사용
  (R=8.314, F=96485 등 — 임의값 사용 금지)
- 문제당 학습 목표 한 가지만 집중
- 로그 값이 필요한 경우 반드시 제공 (log₁₀2=0.3010 등)
