# /validate - 3단계 검증 프로세스

생성된 교재 콘텐츠의 신뢰성을 검증한다.
검증을 통과한 콘텐츠만 진짜 교재가 될 수 있다.

## 사용법
```
/validate [파일경로 또는 drafts/ 전체]
```

## 검증 3단계

---

### 1단계: 수학적 정확성 검증

**검사 항목:**
- [ ] 모든 수식이 올바른가
- [ ] 계산 예시의 답이 맞는가 (직접 재계산)
- [ ] 단위 변환이 올바른가 (mM→M, kJ→J 등)
- [ ] 로그 성질 적용이 올바른가
- [ ] 물리/화학 상수값이 표준값과 일치하는가
  - R = 8.314 J/(mol·K)
  - F = 96,485 C/mol
  - log₁₀2 = 0.3010, log₁₀3 = 0.4771

**오류 발견 시:** 수정 후 재검증. 통과 없이 다음 단계 진행 금지.

---

### 2단계: 교육적 정확성 검증

**검사 항목:**
- [ ] /why → /build → /problems 순서가 논리적으로 연결되는가
- [ ] 각 단계에서 사용되는 개념이 이전 단계에서 설명되었는가
  (사전 설명 없이 갑자기 등장하는 개념 = 실패)
- [ ] 난이도 증가가 급격하지 않은가
- [ ] 전공 문제에 사용된 수식이 /build에서 소개되었는가
- [ ] 학습자가 "왜 이 계산을 하는가"를 알 수 있는가

**오류 유형:**
- JUMP: 설명 없이 개념 도입
- GAP: 난이도 단계 사이 공백 과다
- DISCONNECT: /why의 동기와 /problems의 내용이 무관

---

### 3단계: 출처 검증

**검사 항목:**
- [ ] 수식/공식의 출처가 명시되었는가
- [ ] 인용된 수치 데이터(농도, 상수 등)의 출처가 있는가
- [ ] "일반적으로 알려진" 형태의 근거 없는 주장이 없는가
- [ ] 웹 검색으로 확인 가능한 사실 기반인가

**출처 기준 (우선순위):**
1. 교과서 (Campbell Biology, Lehninger Biochemistry 등)
2. 학술지 논문 (PubMed, arXiv 등)
3. NIST, IUPAC 등 표준 기관 데이터
4. Wikipedia는 보조 참고만 허용 (단독 출처 불가)

**출처 없는 항목 처리:**
- 검색하여 출처 확보 시도
- 출처 확보 불가 → 해당 내용 삭제 또는 "추정값" 명시

---

## 출력 형식
`drafts/[파일명]-validation-report.md` 생성:

```markdown
# 검증 리포트: [파일명]
검증일: [날짜]

## 1. 수학적 정확성
- 상태: PASS / FAIL
- 발견된 오류:
  - [항목]: [오류 내용] → [수정 내용]

## 2. 교육적 정확성
- 상태: PASS / FAIL
- 발견된 문제:
  - [유형 (JUMP/GAP/DISCONNECT)]: [위치] → [권고사항]

## 3. 출처 검증
- 상태: PASS / FAIL
- 출처 확인된 항목: [수]
- 출처 미확인 항목:
  - [항목]: [조치 (삭제|추정값 표시|출처 추가)]

## 최종 판정
[ ] PASS → validated/로 이동 가능
[ ] FAIL → 수정 후 재검증 필요

## 수정 필요 항목 요약
1. [항목] - [우선순위: 높음/보통]
```

## 검증 통과 기준
3단계 모두 PASS여야만 validated/ 이동 허용.
부분 통과 없음. 하나라도 FAIL이면 전체 FAIL.
