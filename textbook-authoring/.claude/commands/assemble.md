# /assemble - 챕터 최종 조합

validated/ 폴더의 파일들을 하나의 완성된 교재 챕터로 조합한다.
검증 통과한 콘텐츠만 사용. drafts/ 파일 직접 사용 금지.

## 사용법
```
/assemble [주제] --format [markdown|latex|docx] --style [교재|강의노트|문제집]
```

## 실행 전 체크
다음 파일이 validated/에 존재하는지 확인:
- [ ] [주제]-why.md
- [ ] [주제]-build.md
- [ ] [주제]-problems-기초.md (선택)
- [ ] [주제]-problems-수학.md (선택)
- [ ] [주제]-problems-전공.md (선택)

미존재 파일이 있으면 중단하고 사용자에게 알림.

## 조합 순서

```
1. 도입부
   - 학습 목표 (2~4개 능력 기술문)
   - 선수 지식 안내

2. 왜 배우는가 ([주제]-why.md)
   - 역사적 맥락
   - 실제 세계 연결

3. 개념 전개 ([주제]-build.md)
   - 직관 → 정의 → 예시 → 성질

4. 문제 (존재하는 레벨만)
   - 기초 문제
   - 수학 문제
   - 전공 문제

5. 마무리
   - 핵심 공식 요약 박스
   - 다음 챕터 예고

6. 참고문헌
   - sources/ 폴더 파일 참조
   - 형식: [번호] 저자. 제목. 출판사/저널, 연도.
```

## 출력
`[주제]-chapter.md` (또는 지정 형식)를 프로젝트 루트에 생성

## 품질 기준
- 챕터 처음부터 끝까지 읽었을 때 흐름이 끊기지 않아야 함
- /why의 동기가 /problems의 전공 문제에서 다시 회수되어야 함
  ("처음에 말한 그게 바로 이 계산이었습니다" 구조)
- 참고문헌 없는 챕터는 완성으로 인정하지 않음
