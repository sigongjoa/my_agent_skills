# Textbook Authoring System

이 폴더는 교재 제작 전용 작업 공간입니다.

## 목적
다른 선생님이나 콘텐츠 개발자가 제공하기 어려운 것을 제공한다:
- "왜 배우는가"부터 시작하는 동기 설계
- 개념 → 계산 가능 수준까지의 완전한 전개
- 수학적 + 교육적 + 출처 검증을 거친 신뢰할 수 있는 콘텐츠

## 작업 규칙
1. 모든 생성된 콘텐츠는 `drafts/`에 저장
2. `/validate` 통과한 것만 `validated/`로 이동
3. `/assemble`은 반드시 `validated/` 파일만 사용
4. 출처 없는 수식, 공식, 데이터는 검증 실패 처리

## 폴더 구조
```
drafts/     - 작업 중인 원고 (검증 전)
validated/  - 검증 완료된 콘텐츠
sources/    - 참고문헌 및 출처 파일
```

## 주제 무관 원칙
로그, 범주론, 튜링 머신 등 어떤 주제에도 동일한 skill 체계 적용.
주제가 바뀌어도 워크플로우는 동일: why → build → problems → validate → assemble
